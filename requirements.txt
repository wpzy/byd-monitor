# BYD Monitor Server 运行依赖
#
# 核心服务只使用 Python 标准库（http.server / urllib / json / ssl / threading），
# 分析引擎同样零第三方依赖，因此本文件不需要任何安装包。

#
# 若将来引入第三方库（如 gunicorn / requests），在此按标准格式追加即可。
